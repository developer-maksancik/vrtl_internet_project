vrtl_internet_alfa is a project created by my 14-year-old self that attempts to simulate a virtual internet within a Python application.
Alpha Version 1.0.0: Contains plenty of bugs, errors, and quirks, but it generally works!

ABOUT THE PROJECT

Goal: Simply to learn something new. While I’ve already covered a lot of Python basics, 
I was lacking practical experience with Object-Oriented Programming (classes) and several other concepts.

Development started: July 25, 2026
First version completed: July 27, 2026

Features: The program was designed as a virtual internet, 
though only the core functionality is implemented so far (classes, functions, etc.). 
It currently features a menu, account switching, and the ability to create and view custom websites. 
Future updates are unlikely, or will be inconsistent at best.

What makes it different from my other projects? It relies heavily on Object-Oriented Programming and avoids spaghetti code. It’s also my largest project to date (over 200 lines of code) and serves as a hands-on application of my newly acquired skills.
ADDITIONAL INFORMATION

I would really appreciate any support or help with development! 
I haven't coded or studied programming in a while (I took a 4-month break before jumping back in). 
I don't expect this program to have practical real-world applications—it was made purely for learning purposes.
